# 个人收支分析

本地优先的个人财务分析桌面应用。账单在本机解析，标准化交易保存在独立 SQLite 数据库文件中；应用不提供账号、云同步、遥测或第三方数据上传。

## 环境要求

- Windows 10/11，WebView2 Runtime
- Node.js 20.19+ 和 pnpm 10+
- Rust stable/MSVC 工具链与 Visual Studio C++ Build Tools

开发依赖通过 pnpm 安装，SQLite 通过 Rust `rusqlite` bundled feature 编译。

## 安装、运行和构建

```powershell
pnpm install
pnpm tauri:dev
```

运行质量检查：

```powershell
pnpm test
pnpm build
cd src-tauri
cargo test
cd ..
```

打包 Windows 桌面安装程序：

```powershell
pnpm tauri:build
```

开发者可在 `pnpm dev` 中查看前端，但需要 Tauri 运行时和本地 SQLite 命令才能使用完整功能。发布版由 Vite 生成静态前端，再由 Tauri 打包为桌面应用。

## 导入账单

在“导入账单”中选择微信 XLSX 或支付宝 CSV（可多选）。解析器在本地扫描账单前 80 行寻找时间和金额表头，并支持手动指定时间、金额和收支方向。预览显示解析数量、异常、排除项、确定重复和疑似重复；异常行不会写入。疑似重复需逐条选择保留为新交易或跳过。用户确认后，所选文件在一个 SQLite 事务中写入；失败时整体回滚。

当前适配器依据仓库内参考账单表头开发（微信表头第 18 行；支付宝 CSV 使用 GB18030，表头第 24 行），但自动化测试只使用模拟数据。其他账单版本仍需实际账单验证。金额以整数分保存。

## 统计口径

- **总支出：** 时间范围内状态已识别、计入统计的消费金额。
- **总收入：** 方向明确的普通收入；退款、内部转账不计入。
- **净收支：** 普通收入 − 总支出 + 时间范围内退款。
- **净消费：** 总支出 − 时间范围内记录的退款。
- **内部转账：** 只有交易类型和账户渠道线索共同指向自有账户划转时才自动排除；不确定的转账进入待确认。
- **退款：** 单独作为退款类型，不会误认为普通收入。同来源、商户、金额吻合且 45 天内只有一个候选时自动关联；没有唯一候选的退款保留为待确认项，不计入净消费抵减。
- **去重：** 同平台交易单号优先；没有单号时使用来源、指纹、时间、金额和商户进行严格重复判断。时间、金额与商户近似但证据不足时作为疑似重复，交由用户处理。

## 数据库存储与隐私

首次启动时在系统用户数据目录创建 `expenses.db`。Windows 默认位于 `%APPDATA%\com.expenselens.local\expenses.db`（实际文件位置会在“数据管理”页面显示）。SQLite 使用 WAL 模式；schema 版本记录在 `PRAGMA user_version`，首个可重复迁移位于 `src-tauri/migrations/001_initial.sql`。后续迁移必须以新版本脚本追加，不得删除或重置用户已有数据库。

数据库不在仓库或安装目录中。设置页可查看、迁移数据库位置、备份和恢复。选择另一个位置时应用使用 SQLite 在线备份 API 创建一致副本，迁移成功后仍保留旧文件。账单原文件由用户自行归档。

建议定期在“数据管理”页面创建 SQLite `.db` 备份，或导出完整 JSON 业务数据，并保存到安全位置。SQLite 备份通过 SQLite 在线备份 API 获取一致快照，即使数据库处于 WAL 模式也包含已提交数据。JSON 备份包含交易、分类、规则、导入批次、重复决策和审计信息。恢复支持合并或完整替换：合并时保留当前记录及用户修改，冲突会出现在恢复报告；完整替换会在二次确认后覆盖当前业务数据。交易 CSV 可按当前统计日期范围导出。

卸载应用、删除用户数据目录或清理系统文件可能造成未备份数据丢失。恢复前建议先创建当前数据库备份。数据目录、备份、导出和仓库中的 `reference/` 账单目录都在 `.gitignore` 中排除；提交前仍应检查 `git status`。

## 目录结构

- `src/importers/`：微信 XLSX 与支付宝 CSV 适配器
- `src/domain/`：金额、收支分类、去重及业务测试
- `src/`：React 页面与设计系统样式
- `src-tauri/src/`：Tauri 命令与 SQLite 数据访问
- `src-tauri/migrations/`：数据库 schema 迁移

## 当前限制

- 当前 UI 主要针对桌面窗口，最小宽度约 1080px；小屏和触屏适配尚未达到移动应用级体验。
- 交易查询以 500 笔为一页按需加载；搜索和筛选作用于已载入记录。大量历史数据可继续点击“加载更多交易”。
- 自定义规则目前按商户/描述中的关键词匹配，作用于之后导入的交易；不会自动回写修改既有交易。
- CSV 编码自动识别优先尝试 UTF-8，失败时回退 GB18030；尚未对所有导出版本和编码变体验证。
- 本仓库参考账单只用于查看格式和表头；未将其中真实交易行作为测试数据或提交到仓库。
